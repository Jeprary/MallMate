# Cloud orb

The Cloud shader in cloud-orb.js is adapted from Mizu / Orb UI. MallMate supplies its own Jade palette, light gain, visual lifecycle and voice-state adapter. No research page or screenshot is bundled.

Mizu Cloud/Mist rendering and motion adapted from:
https://github.com/dyascj/mizu/tree/main/src/lib/components/ui/voice-orb
Cloud renderer adapted upstream from https://github.com/exprmntl/orb-ui

# Phosphor Icons

Static Regular-weight SVG assets from `@phosphor-icons/core` 2.1.1. Exact files, source URLs, byte sizes and SHA-256 hashes are recorded in `assets/icons/phosphor/manifest.json`. The viewBox and geometry are preserved; inline wrappers add sizing and accessibility attributes.
